# تصمیم‌ها و موارد نیازمند تأیید

این فایل انتخاب‌های فعلی را از فرض‌ها جدا می‌کند.

## تصمیم‌ها و پیشنهادهای فعلی

| موضوع | وضعیت | توضیح |
|---|---|---|
| مخزن | خصوصی | پروژه فعلاً شخصی است. |
| هدف سیستم‌عامل | Windows 11 | هدف فعلی استفاده و توسعه. |
| سرور اختصاصی | ندارد | دانلود مستقیم از میزبان فایل انجام می‌شود. |
| هسته | Rust، پیشنهادی | انتخاب اولیه، نیازمند امکان‌سنجی. |
| رابط | WinUI 3 + C#، پیشنهادی | انتخاب اولیه برای دسکتاپ ویندوز. |
| پایگاه داده | SQLite، پیشنهادی | ذخیره‌سازی محلی صف و وضعیت. |
| ارتباط UI/Core | C ABI و P/Invoke، پیشنهادی | پس از آزمون کوچک تأیید یا تغییر می‌شود. |
| دانلود چندبخشی | مرحلهٔ بعد | فقط در صورت پشتیبانی میزبان. |
| افزونهٔ مرورگر | خارج از نسخهٔ نخست | پس از پایدارشدن دانلود مستقیم بررسی شود. |
| آغاز کدنویسی | متوقف تا تأیید اسناد | ابتدا نقشه و نیازمندی‌ها. |

## مواردی که کاربر باید مشخص کند
1. تصویر پنجرهٔ اصلی نسخهٔ IDM مورد استفاده و در صورت امکان پنجرهٔ افزودن لینک؛ اطلاعات خصوصی در تصاویر پوشانده شوند.
2. زبان رابط: انگلیسی، فارسی یا هر دو.
3. ضروری‌ترین قابلیت‌ها برای نسخهٔ نخست.
4. اجزای بصری IDM که شباهتشان بیشترین اهمیت را دارد.
5. نام و آیکون مستقل برنامه.
6. تأیید معماری نهایی پس از امکان‌سنجی ارتباط Rust و WinUI.

## قانون تغییر تصمیم
هر تغییر مهم باید همراه با دلیل، گزینه‌های بررسی‌شده، مزایا/معایب و نتیجه ثبت شود. تغییرات معماری در مستندات بازبینی شوند، نه اینکه بی‌توضیح در کد وارد شوند.
