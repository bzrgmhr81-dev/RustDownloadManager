# RustDownloadManager

یک دانلودمنیجر ویندوزی که فعلاً برای **استفادهٔ شخصی مالک پروژه** ساخته می‌شود. مخزن GitHub در زمان آخرین بررسی **عمومی (Public)** است؛ این موضوع به معنی تصمیم برای تجاری‌سازی یا انتشار یک محصول تجاری نیست.

> **وضعیت فعلی: برنامه‌ریزی و مستندسازی؛ کدنویسی برنامه هنوز آغاز نشده است.**  
> اسناد پیش‌نویس‌اند و پیش از پیاده‌سازی باید بازبینی و تأیید شوند.

## هدف محصول

بازسازی تجربهٔ کار با IDM تا حد ممکن دقیق، به‌ویژه چیدمان پنجرهٔ اصلی، نوار ابزار، درخت گروه‌ها، ترتیب ستون‌ها و گردش‌کارها. زیباسازی فقط در صورتی انجام می‌شود که ساختار مرجع حفظ شود یا مالک تغییر را تأیید کند.

### قاعدهٔ کلیدی رابط

بر اساس بازبینی تصویر مرجع IDM 6.43، ساختار پنجره **چپ‌به‌راست (LTR)** است: درخت گروه‌ها سمت چپ و جدول دانلودها سمت راست قرار می‌گیرد. متن‌های فارسی داخل کنترل‌ها باید راست‌چین نمایش داده شوند، اما نباید کل پنجره به‌صورت RTL آینه شود. این فرض باید در نمونهٔ رابط با نسخهٔ نصب‌شدهٔ مالک تأیید شود.

## فناوری‌ها و گزینه‌های هنوز تأییدنشده

- چارچوب رابط: WinUI 3 یا WPF با C#؛ تصمیم پس از آزمایش نمونهٔ کوچک.
- هستهٔ دانلود: تماماً C# یا Rust؛ انتخاب هنوز باز است.
- اگر Rust انتخاب شود، روش اتصال پیشنهادی باید میان C ABI/P/Invoke و یک فرایند جدا با Named Pipe/JSON مقایسه شود.
- ذخیره‌سازی محلی: SQLite به‌عنوان گزینهٔ پیشنهادی.
- شبکه: اتصال مستقیم به میزبان فایل؛ سرور اختصاصی یا حساب ابری در محدودهٔ فعلی نیست.

## اصول پروژه

1. هدف فعلی استفادهٔ شخصی است؛ مخزن عمومی است، اما برنامهٔ تجاری در محدودهٔ فعلی نیست.
2. ساختار و گردش‌کار IDM در اولویت‌اند؛ زیباسازی نباید باعث تغییر ناخواستهٔ آن‌ها شود.
3. جهت چیدمان LTR و راست‌چین بودن متن فارسی دو موضوع جدا هستند.
4. چارچوب رابط و روش ارتباط با هسته تا زمان آزمایش قطعی نمی‌شوند.
5. پیش از تأیید مستندات و معیارهای پذیرش، کدنویسی برنامه آغاز نمی‌شود.
6. امنیت، صحت فایل و پایداری از رسیدن به زمان‌بندی مهم‌ترند.
7. چون مخزن عمومی است، هیچ رمز، توکن، کوکی، URL محرمانه، نام فایل شخصی یا تصویر حاوی اطلاعات خصوصی نباید وارد GitHub شود.
