# RustDownloadManager

یک پروژهٔ شخصی برای ساخت دانلودمنیجر ویندوزی با گردش‌کاری آشنا به IDM، اما با کد و هویت مستقل و بدون نیاز به کرک یا سرور اختصاصی.

> **وضعیت: برنامه‌ریزی و مستندسازی. کدنویسی برنامه هنوز آغاز نشده است.**  
> این اسناد پیش‌نویس‌اند و پیش از پیاده‌سازی باید با کاربر بازبینی و تأیید شوند.

## هدف
ساخت برنامه‌ای برای Windows 11 جهت مدیریت دانلودهای مستقیم HTTP/HTTPS، مشاهدهٔ سرعت و پیشرفت، کنترل صف و ادامهٔ دانلود در صورت پشتیبانی سرور، و بازیابی وضعیت پس از اجرای مجدد.

## فناوری‌های پیشنهادی
- رابط: WinUI 3 با C# و .NET
- هستهٔ دانلود: Rust
- پایگاه دادهٔ محلی: SQLite
- ارتباط رابط و هسته: گزینهٔ اولیه، کتابخانهٔ Rust با C ABI و فراخوانی از C#؛ باید پیش از تأیید نهایی آزمایش شود.
- شبکه: اتصال مستقیم به میزبان فایل؛ هیچ سرور اختصاصی یا حساب ابری برای برنامه در نظر گرفته نشده است.

## اصول
1. پیش از تأیید اسناد، کدنویسی آغاز نمی‌شود.
2. هر مرحله کوچک، قابل بررسی و قابل آزمایش باشد.
3. امنیت، صحت فایل و پایداری از رسیدن به زمان‌بندی مهم‌ترند.
4. هدف، تجربهٔ کاربری مستقل و نزدیک به گردش‌کار مورد پسند کاربر است؛ نشان، لوگو و فایل‌های اختصاصی IDM کپی نمی‌شوند.
5. رمزها، کوکی‌ها، توکن‌ها و URLهای حساس نباید وارد مخزن یا گزارش خطا شوند.
