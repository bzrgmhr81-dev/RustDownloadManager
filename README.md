# RustDownloadManager

یک دانلودمنیجر ویندوزی برای **استفادهٔ شخصی و خصوصی**. در حال حاضر قصد فروش، تجاری‌سازی یا انتشار عمومی پروژه وجود ندارد.

> **وضعیت فعلی: برنامه‌ریزی و مستندسازی؛ کدنویسی برنامه هنوز آغاز نشده است.**  
> این اسناد پیش‌نویس‌اند و پیش از پیاده‌سازی باید بازبینی و تأیید شوند.

## هدف محصول

ساخت برنامه‌ای برای Windows 11 که برای استفادهٔ شخصی، تجربه و چیدمان رابط IDM را تا حد ممکن دقیق بازسازی کند. **اولویت اصلی حفظ ساختار، جایگاه اجزا، ترتیب ستون‌ها، گروه‌های دانلود و گردش‌کار IDM است.** ظاهر می‌تواند در صورت رضایت کاربر مرتب‌تر یا زیباتر شود، اما نباید با بهانهٔ مدرن‌سازی، چیدمان اصلی تغییر کند یا اجزای مهم حذف شوند.

مرجع نهایی جزئیات رابط، تصویر واقعی نسخهٔ IDM مورد استفادهٔ کاربر است. تا وقتی تصویرها و رفتارها بررسی و تأیید نشده‌اند، اندازه‌ها و جزئیات دقیق قطعی نیستند.

## فناوری‌های پیشنهادی (هنوز نهایی نشده)

- رابط کاربری: WinUI 3 با C# و .NET
- هستهٔ دانلود: Rust، مشروط به تأیید پس از بررسی گزینه‌های ساده‌تر و روش ارتباط
- ذخیره‌سازی محلی: SQLite
- گزینه‌های ارتباط UI/Core برای ارزیابی: C ABI/P/Invoke، پردازش جداگانهٔ Rust با Named Pipe و JSON، یا پیاده‌سازی تماماً با C#
- شبکه: اتصال مستقیم به میزبان فایل؛ سرور اختصاصی یا حساب ابری در محدودهٔ فعلی نیست.

## اصول پروژه

1. کاربرد فعلی شخصی و خصوصی است؛ تجاری‌سازی یا انتشار عمومی در برنامهٔ فعلی نیست.
2. وفاداری چیدمان و گردش‌کار IDM از بازطراحی سلیقه‌ای رابط مهم‌تر است.
3. ظاهر می‌تواند بهبود یابد، اما تغییر چیدمان، حذف گروه‌ها یا تغییر ترتیب ستون‌ها نیازمند تأیید کاربر است.
4. معماری فنی و اتصال میان زبان‌ها قبل از آزمایش قطعی نمی‌شوند.
5. پیش از تأیید مستندات، کدنویسی آغاز نمی‌شود.
6. امنیت، صحت فایل و پایداری از رسیدن به زمان‌بندی مهم‌ترند.
7. رمزها، کوکی‌ها، توکن‌ها و URLهای حساس نباید وارد مخزن یا گزارش خطا شوند.
